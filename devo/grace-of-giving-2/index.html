The Grace of Giving: A Cheerful Heart

A 5-Day Devotional. Five emails, one per morning. The button copies the finished email; the pictures load by themselves.

How to schedule each day (about 3 minutes per day)

  1. Click the Copy Day 1 code button below.
  2. In Mailchimp: Create → Email → choose Code your own → Paste in code. Paste (Ctrl+V or Cmd+V) and save.
  3. Set the audience, then copy the Subject line and Preview text from the card.
  4. Send a test to yourself and look at it on your phone.
  5. Schedule it for the date and time on the card. Then do Day 2, 3, 4 and 5 the same way.

If a Copy button does nothing, the code appears in a box under it: click in the box, press Ctrl+A (Cmd+A on a Mac), then copy.
