Tomorrow (Fri Nov 13): proof of concept

Laura, this is the first email in the new design. It replaces the Day 5 email you already scheduled, at the same time.

Swap tomorrow's scheduled email for the new design (about 5 minutes)

  1. Click the red Copy Day 5 code button below. It says "Copied" when it worked.
  2. In Mailchimp, open Campaigns (or All campaigns) and find the devo email already scheduled for Friday, November 13, 2026.
  3. Open it and click Pause (some screens say Unschedule). If Mailchimp won't let you change the design, use Replicate instead and work on the copy; then delete or keep the old one unscheduled so only ONE goes out.
  4. Go to Edit design (or Design email) and choose Code your own → Paste in code. Delete the old code, paste (Ctrl+V or Cmd+V) and Save.
    If you only see the drag-and-drop editor: remove the old content blocks, drag in a Code (HTML) block, paste the code into it and save.
  5. Check the Subject line and Preview text (copy them from the card below if you like the new ones).
  6. Click Send a test to yourself and open it on your phone: the Capitol header, "Day 5 of 5", the devotional and the red "Read the whole week" button should all show.
  7. Click Schedule and set it for the same time as before (Friday, November 13, 2026, 6:00 AM Pacific time unless yours was different). Make sure it says Scheduled.

If a Copy button does nothing, the code appears in a box under it: click in the box, press Ctrl+A (Cmd+A on a Mac), then copy.

Not for this week (those days already went out). This is how every day will look from the next devo on: each morning gets its own email, scheduled the same way as tomorrow's.

Next time: how to schedule each day (about 3 minutes per day)

  1. Click the red Copy Day 1 code button below.
  2. In Mailchimp: Create → Email → choose Code your own → Paste in code. Paste (Ctrl+V or Cmd+V) and save.
  3. Set the audience, then copy the Subject line and Preview text from the card.
  4. Send a test to yourself and look at it on your phone.
  5. Schedule it for that day's morning (the page will list the dates). Then do Day 2, 3, 4 and 5 the same way.

If a Copy button does nothing, the code appears in a box under it: click in the box, press Ctrl+A (Cmd+A on a Mac), then copy.
